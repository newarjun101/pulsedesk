# Project Context

- **Product**: Multi-tenant SaaS for Social Media Management, Community Management, and Customer Support.
- **Initial Platforms**: Facebook (Meta Graph API & Messenger), Instagram (Instagram Graph API), TikTok (Official TikTok APIs).
- **Architecture**: Modular monolith (NestJS) + Next.js App Router frontend + PostgreSQL (Prisma) + Redis (BullMQ) + S3-compatible storage.
- **Current Phase**: Phase 1 — Project Foundation.
